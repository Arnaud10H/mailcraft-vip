- **A link can start a message written in HTML.** A `mailto:` link may carry `html`, a whole message laid out in HTML elsewhere (Radar's illustrated e-mails, a newsletter tool): MailCraft opens it as if it had been pasted with `compose.html` (shown whole, cleaned of anything that runs or tracks, sent as written, your signature after it), with the link's `body` as the plain-text stand-in other mail programs keep. A link handed to a MailCraft already open may now be 64 KB.
