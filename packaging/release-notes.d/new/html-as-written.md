- **A message written in HTML elsewhere goes out as written.** Paste a whole message laid out in HTML (a table, pictures) into a new message, or have an agent hand one over (`compose.html`, with the HTML or an .html file): the window shows a simpler copy, and the HTML is sent with its layout and colours, without anything that runs or tracks, its pictures written into it going with it. Editing the copy sends the copy instead. An HTML signature with pictures of its own also keeps its HTML when MailCraft starts again.
