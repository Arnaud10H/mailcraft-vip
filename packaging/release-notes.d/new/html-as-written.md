- **HTML shown and sent as it is.** An HTML signature, and a whole message laid out in HTML (pasted into a new message, or handed over by an agent with `compose.html`), are shown whole below the text you write, exactly as recipients will see them, and sent as written without anything that runs or tracks; pictures written into them go with the message. "Edit as Text" and "Signature as Text" turn them into text to edit; a draft opened again keeps them whole. An HTML signature with pictures pastes whole, or comes from a file, and keeps its HTML when MailCraft starts again.
